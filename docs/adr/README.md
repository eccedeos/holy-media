# Architecture Decision Records

Cada arquivo aqui registra **uma decisão** que seria cara de reverter depois, com
o contexto que a motivou e as alternativas que foram descartadas.

O objetivo não é burocracia: é que daqui a seis meses ninguém precise adivinhar
por que o projeto não usa um ORM, e não desfaça a decisão por engano.

| #    | Decisão                                 | Status |
| ---- | --------------------------------------- | ------ |
| 0001 | Monorepo enxuto: só o que já é usado    | Aceito |
| 0002 | SQLite acessado do Rust, sem ORM        | Aceito |
| 0003 | Controle remoto nasce como PWA          | Aceito |
| 0004 | Segunda tela é uma segunda janela Tauri | Aceito |
